\chapter{Лабораторная работа №1.1. Введение в MATLAB. Переменные, функции, графика}
\label{ch:chap1}

\section{Цель работы}
\label{sec:goal1}

    Изучение системы MATLAB для инженерных, финансовых и математических расчётов. Выполнение учебного математического расчёта: построение графиков функции, её производной и интеграла, решение уравнения, построение трёхмерного графика.

\section{Задание к лабораторной работе}
\label{sec:task1}

    В соответствии с методическими указаниями \cite{andreev2024tmo} необходимо:

    \begin{enumerate}
        \item Определить функцию $f(x)$, заданную по варианту №24:
        \begin{equation}
        \label{eq:f}
            f(x) = \frac{2 \pi e^{\cos(x)}}{-x^2}.
        \end{equation}
        \item Построить графики функции $f(x)$, её производной $f'(x)$ и интеграла $F(x) = \int_{x_0}^{x} f(y) \, dy$.
        \item Решить уравнение вида $a \cdot x + b = f(x)$ графическим и аналитическим методами. Коэффициенты $a$ и $b$ задать самостоятельно. Использовать функцию \verb|fsolve| для численного решения.
        \item Определить функцию двух переменных $F(x,y)$ по варианту №24:
        \begin{equation}
        \label{eq:F}
            F(x,y) = \sqrt{|\ln(x) - \ln(y)|}.
        \end{equation}
        \item Построить трёхмерный график $F(x,y)$ с использованием \verb|meshgrid| и \verb|surf|.
        \item Подписать все графики с помощью \verb|title|, \verb|xlabel|, \verb|ylabel|, добавить легенды \verb|legend|.
    \end{enumerate}
